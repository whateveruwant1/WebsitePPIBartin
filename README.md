# Website PPI Bartın

Website sederhana untuk Perhimpunan Pelajar Indonesia (PPI) di Bartın menggunakan Flask.

## Fitur

- Halaman profil organisasi lengkap (visi, misi, program, agenda, pengurus).
- Form kontak yang menampilkan halaman ucapan terima kasih.
- Desain responsif dengan CSS modern.

## Menjalankan Aplikasi

1. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```
2. Jalankan server:
   ```bash
   python app.py
   ```
3. Buka browser ke `http://localhost:5000`.

## Struktur Proyek

- `app.py` - aplikasi Flask.
- `templates/` - template HTML.
- `static/` - aset CSS.
